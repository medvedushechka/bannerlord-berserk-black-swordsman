# Установка — черновик для тестировщиков

**Статус: не готово к установке одним кликом.** Это точный манифест локальной сборки, а не опубликованная коллекция.

1. Используйте Bannerlord **1.4.8.119303** и War Sails **1.2.8.119303**. На других сборках совместимость не проверена.
2. Устанавливайте сторонние моды только из оригинальных источников, соблюдая требования авторов.
3. Сверяйте версии и порядок **строго** с `manifest/current-load-order-2026-11-08.csv`. Все 41 модуля отмечены включёнными.
4. Проверьте DLL и зависимости. Различия между Vortex staging и `Modules` для BetterBanditsPlus / ImprovedGarrisons не означают, что следует ставить более новые версии.
5. `UpgradeGuard_v6` устанавливайте только после изучения `patches/UpgradeGuard_v6/README_RU.txt`; его код пока экспериментальный.
6. Начинайте с нового сохранения, тестируйте экран отряда, улучшение бандитов, крупные сражения, осады, DLC и повторную загрузку игры.

**Не выкладывайте** `state.v2`, профили с личными данными, чужие архивы модов, игровые DLL или личные сохранения. Nexus Collection должна ссылаться на файлы модов у их авторов.
