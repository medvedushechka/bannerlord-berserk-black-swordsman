# План публикации Nexus Collection

1. Создать отдельный профиль Vortex для **Berserk Black Swordsman**; убедиться, что активные моды соответствуют `manifest/current-load-order-2026-11-08.csv`.
2. Проверить, что все моды установлены с корректными Nexus mod ID / file ID. Для вручную установленных файлов определить допустимый способ распространения.
3. Проверить зависимости и разрешения; не включать чужие бинарники в GitHub.
4. Создать Collection в Vortex из нужного профиля, сохранить настройки порядка загрузки и требования.
5. Установить коллекцию на **чистом тестовом профиле** и пройти тесты: запуск, новая кампания, бои, апгрейд войск, осады, War Sails.
6. После успешного теста добавить ссылку на коллекцию в README и только затем пометить версию как стабильную.

## Известные риски

- Список из LauncherData.xml показывает **порядок и флаги**, но не гарантирует, что Vortex сможет автоматически загрузить каждый мод.
- `BannerlordUpgradeGuard` — локальный патч; до публичного релиза требуется проверить его сборку из исходников и лицензию.
- `AutoTrader` ссылается на `CargoHolds`, которого нет в списке модулей.
